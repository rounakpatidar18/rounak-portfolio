# Personal Portfolio Website

## Overview
A modern, multi-page **personal portfolio website** built with **React**, showcasing my development work and skills. This project follows best practices in React development using **hooks**, reusable components, and optimized rendering for enhanced performance.  

The portfolio is styled with modern CSS and is fully **responsive**, providing a smooth user experience across all devices. 

## Features
- Built with **React** using functional components and **Hooks**.
- Responsive and modern **CSS** design.
- Clean, multi-page layout with four main sections:
  - **Home** – Introduction and welcome.
  - **About** – Overview of skills, experience, and background.
  - **Projects** – Showcase of development work.
- Optimized components and rendering for improved performance.
- Reusable and modular code for easy maintenance and scalability.

## Technologies Used
- **React**
- **React Hooks**
- **CSS / Responsive Design**
- Performance Optimization Techniques
